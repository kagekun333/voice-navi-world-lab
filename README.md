# VOICE NAVI Public Beta

This repository is the public static deployment for VOICE NAVI.

It intentionally contains only browser runtime assets and the currently approved public beta Voice Packs:

- `ja-standard`
- `ja-kansai`

Internal development, candidate, research, and operational data are not published here.

Browser-delivered HTML/CSS/JavaScript and the two public beta Voice Packs are public by nature and can be inspected or copied by visitors.

## Global Free Beta

Try the 13-language, 16-pack experimental free system-voice preview:
https://kagekun333.github.io/voice-navi-world-lab/beta/

The original root catalog still has only two approved public beta packs.
The separate Beta features 13 standard-language references and four unverified
regional wording pilots, including Geordie/Tyneside. Regional accents are NOT certified, availability
depends on device/browser voices, and the prototype is not live navigation.
Remote TTS voices require explicit opt-in; feedback remains on the visitor device.
No research audio, internal Factory data, rights records or paid voice jobs are published.

Geordie lexical source: Newcastle University (individual word meanings only; no endorsement of generated speech): https://belong.ncl.ac.uk/blog/geordie-dictionary-guide
