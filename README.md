# VOICE NAVI Public Voice Preview

This repository is the public static deployment for VOICE NAVI.

It intentionally contains only browser runtime assets and the currently approved public Release voice packs:

- `ja-standard`
- `ja-kansai`

Internal development, candidate, research, and operational data are not published here.

Browser-delivered HTML/CSS/JavaScript and the two public Release packs are public by nature and can be inspected or copied by visitors.
